## 🕹️ Overview

LIV is the leading mixed reality capture tool for VR streamers and YouTubers, supporting avatar cameras, MR compositing, and direct streaming integrations.

Whether you're a newcomer or a veteran, LIV provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Avatar Camera** | Place a virtual camera anywhere in your VR scene |
| **MR Compositing** | Real-time greenscreen compositing with your physical camera |
| **Streaming Ready** | Direct output to OBS, XSplit, and other broadcast tools |
| **Avatar Support** | Compatible with VRChat avatars and VRM models |
